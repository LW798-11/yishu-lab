# 易数实验室 · I Ching Mathematics Lab

把《易经》起卦的全过程写成公开、可复算的数学运算：二进制表示、模运算、变换群、概率推导与蒙特卡洛验证。

*A web app that models I Ching casting as mathematics: hexagrams as 6-bit vectors over F₂, transformations as group actions and linear maps, and the coin vs. yarrow-stalk methods as probability distributions, verified by Monte Carlo simulation.*

在线体验：https://lw798-11.github.io/yishu-lab/

## 核心思想

六十四卦就是 F₂⁶（由 0 和 1 组成的长度为 6 的向量，共 2⁶ = 64 个）。每一爻是一个比特（阳 = 1，阴 = 0），三爻卦是 F₂³（8 个），一个六爻卦是一对（下卦，上卦）。起卦、卦变这些传统操作，各自对应这个空间上的一种数学操作：

| 传统概念 | 数学对象 |
|---|---|
| 错卦（阴阳全反） | 平移：x ↦ x ⊕ 111111 |
| 变卦（动爻翻转） | 平移：x ↦ x ⊕ eᵢ（eᵢ 为第 i 位的单位向量） |
| 综卦（上下颠倒） | 坐标置换：(b₀…b₅) ↦ (b₅…b₀) |
| 互卦（取 2-3-4、3-4-5 爻） | F₂ 上的线性映射，秩为 4，**不可逆** |
| 起卦（铜钱 / 蓍草） | 一爻的取值是一个随机变量，见下文 |

## 功能与数学原理

### 一、起卦

**数字取模 / 时间取模**（确定性函数，同一输入永远得到同一个卦，任何人都可以重算）

- 本站约定：N mod 8 定上卦，⌊N/8⌋ mod 8 定下卦，N mod 6 定动爻（余 0 记为上爻）。
- 说明：这是本站对单个数字的一种拆分方式；传统梅花易数通常用两个数分别定上、下卦。
- 时间起卦用年月日时的干支序数取模，数学上与数字法等价。

**铜钱法**：三枚铜钱，字 = 3，背 = 2，三钱之和 S ∈ {6, 7, 8, 9}，S = 6 + Bin(3, 1/2)。

**大衍揲蓍**：忠实模拟「分二、挂一、揲四、归奇」三变程序。

**两种方法的统一写法**：一爻的取值可以写成 9 − (A + B + C)，其中 A、B、C 是三个独立的 0-1 随机变量。

- 铜钱法：A、B、C 都是公平的（p = 1/2）。
- 大衍法：B、C 是公平的，**A 的 p = 1/4**。原因是第一变中，挂一后剩 48 根，分成两堆后左右余数之和只可能是 4（对应归奇共 5）或 8（对应归奇共 9）。在分堆位置对 4 取模均匀分布的假设下，出现 8 的概率为 1/4；第二变、第三变的归奇共 4 或共 8，各占 1/2。

| 取值 | 名称 | 铜钱法 | 大衍法 |
|---|---|---|---|
| 6 | 老阴（变） | 1/8 | 1/16 |
| 7 | 少阳 | 3/8 | 5/16 |
| 8 | 少阴 | 3/8 | 7/16 |
| 9 | 老阳（变） | 1/8 | 3/16 |

两种方法下，一爻为阳的概率都是 1/2，一爻会变的概率都是 1/4（因为 A+B+C 为偶数的概率不依赖 A，B 是公平的）。**区别在条件概率**：

- 铜钱法：阳爻变和阴爻变的概率都是 1/4，对称。
- 大衍法：阳爻变的概率是 3/8，阴爻变的概率只有 1/8，**阳爻变的可能性是阴爻的 3 倍**。

### 二、本卦：六爻即一个 6 位二进制数

每个卦展示卦画、二进制值和加权求和过程。**位序约定**：底爻为最低位（2⁰），上爻为最高位（2⁵），阳 = 1。

例：天地否，初→上为 阴阴阳阳阳阳，即 0b111000（b₅…b₀）= 8 + 16 + 32 = 56。

**先天（伏羲）卦序**依邵雍原序（朱熹《易学启蒙》所载）：乾一、夬二……泰八……否五十七……坤六十四。由二进制值换算的公式是：

```
伏羲序号 = bitrev₆(63 − 值) + 1      （bitrev₆：6 位二进制倒序）
```

等价说法：从上爻起数、阴爻记 1 读出的值，再加 1。例：否的值 56，63 − 56 = 7 = 0b000111，倒序得 0b111000 = 56，故为伏羲第 **57** 卦；泰为第 8，乾为第 1，坤为第 64。

### 三、卦变的代数结构

- **错卦、变卦是平移，综卦是坐标置换，三者都是 F₂⁶ 上的可逆变换**；{恒等, 错, 综, 错∘综} 构成克莱因四元群（错与综可交换）。
- 在这个群的作用下，64 卦分成 **20 个轨道**：12 个轨道各含 4 卦，8 个轨道各含 2 卦。8 个小轨道各含两个不动点：一个被综卦固定（回文卦，如乾、坤、坎、离、颐、大过、中孚、小过），一个被错∘综固定（反回文卦）。（由 Burnside 引理：(64 + 0 + 8 + 8) / 4 = 20。）
- 变卦作用相当于在 6 维超立方体 Q₆ 上沿一条边移动；错卦把一个卦映到它的对径点（距离 6）。
- **互卦是线性映射但不可逆**：把 64 卦映到 16 个卦，每个互卦恰有 4 个本卦，所以它不属于任何变换群。

### 四、蒙特卡洛：把占卜交给大数定律

一键模拟两种起卦法各 1–100,000 次，频率直方图与理论概率线对比。随着样本量增大，频率收敛到上表的理论值；铜钱法的变爻频率对阴阳对称，大衍法不对称。

### 五、首页背景：Rule 90 元胞自动机

阴阳二值按「左右邻居异或」迭代：xᵢ(t+1) = xᵢ₋₁(t) ⊕ xᵢ₊₁(t)。这个规则在 F₂ 上是线性的，从单个种子出发，第 t 行是二项式系数 C(t, k) 模 2，由此生长出谢尔宾斯基三角形。它和六十四卦用的是同一个数域 F₂。

## 复算数学结论

`verify_math.py` 用纯 Python 复算上面的全部结论（两种起卦法的精确概率、克莱因四元群的轨道数、互卦的秩与像、伏羲序号等）：

```bash
python verify_math.py
```

输出 `all checks passed` 即全部通过。

## 约定与局限

- 位序、梅花易数的数字拆分方式、伏羲序号都是明确写出的约定，换一种约定会得到不同的编号。
- 大衍法的 1/4 假设「分堆位置对 4 取模均匀分布」，这是对真实分堆过程的理想化。
- 卦辞作为传统文化文本展示，不构成任何决策建议。本项目研究的是起卦过程的数学结构，不声称它能预测任何事情。
