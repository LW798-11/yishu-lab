## 功能与数学原理

### 一 · 起卦：三次模运算，或一场随机实验

| 方法 | 数学本质 |
|---|---|
| 数字取模 | `N mod 8` 定上卦，`⌊N/8⌋ mod 8` 定下卦，`N mod 6` 定动爻（梅花易数规则） |
| 时间取模 | 年月日时干支序数取模，与数字法数学等价 |
| 铜钱模拟 | 三枚铜钱，字面 3 背面 2，三钱之和 ∈ {6,7,8,9}，概率 1/8、3/8、3/8、1/8（二项分布） |
| 大衍揲蓍 | 忠实模拟「分二、挂一、揲四、归奇」三变程序；老阴概率仅 1/16，与铜钱法不同 |

数字/时间起卦是**确定性函数**：同一个输入永远得到同一个卦，任何人都可以重算验证。

### 二 · 本卦：六爻即一个 6 位二进制数

六十四卦就是 0–63 的全部 6 位二进制数。每个卦同时展示卦画、二进制值、加权求和过程与先天（伏羲）卦序——例如「天地否」= `111000` = 8+16+32 = **56**，伏羲第 **8** 卦。

### 三 · 卦变：本卦在变换群下的轨道

传统卦变用群论语言描述，是作用在 6 位二进制向量上的四种变换：

- **错卦**：按位取反 `x ↦ x ⊕ 111111`（Z₂⁶ 群作用）
- **综卦**：倒序 `(b₀…b₅) ↦ (b₅…b₀)`（旋转 180°）
- **互卦**：抽取 2,3,4 / 3,4,5 爻重组（取核）
- **变卦**：翻转动爻对应比特 `0 ↔ 1`

### 四 · 蒙特卡洛：把占卜交给大数定律

一键模拟两种起卦法各 1–100,000 次，频率分布直方图与理论概率线对比：铜钱法对称，大衍法非对称（少阳 5/16 > 少阴 7/16 之外的权重），样本量越大越贴合理论线。

首页背景是 **Rule 90 元胞自动机**——阴阳二值按「左右邻居异或」迭代，生长出谢尔宾斯基三角形分形。

## 本地运行

本仓库发布的是单文件构建产物（`index.html`，内联全部 CSS/JS）。开发源码为 React + TypeScript + Vite + Tailwind CSS：

```bash
npm install
npm run dev      # 开发预览
npm run build    # 构建到 dist/
```
