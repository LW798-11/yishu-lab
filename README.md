## 功能与数学原理

### 一 · 起卦：三次模运算，或一场随机实验

| 方法 | 数学本质 |
|---|---|
| 数字取模 | `N mod 8` 定上卦，`⌊N/8⌋ mod 8` 定下卦，`N mod 6` 定动爻（梅花易数规则） |
| 时间取模 | 年月日时干支序数取模，与数字法数学等价 |
| 铜钱模拟 | 三枚铜钱，字面 3 背面 2，三钱之和 ∈ {6,7,8,9}，概率 1/8、3/8、3/8、1/8（二项分布） |
| 大衍揲蓍 | 忠实模拟「分二、挂一、揲四、归奇」三变程序；老阴概率仅 1/16，与铜钱法不同 |

数字/时间起卦是**确定性函数**：同一个输入永远得到同一个卦，任何人都可以重算验证。

### 二 · 本卦：六爻即一个 6 位二进制数

六十四卦就是 0–63 的全部 6 位二进制数。每个卦同时展示卦画、二进制值、加权求和过程与先天（伏羲）卦序。约定写清，两不相混：

- **二进制值**：初爻为最低位（b₀ = 初爻）、阳 = 1。例：「天地否」初→上为 阴阴阳阳阳阳，即 0b111000（b₅…b₀）= 8+16+32 = **56**。
- **伏羲卦序**：依邵雍原序（朱熹《易学启蒙》所载）：上爻为最低位、阴爻记 1，读出的值再加 1。例：否的上→初为 阳阳阳阴阴阴，即 0b000111（b₀ = 上爻）= 56，故为第 **57** 卦；泰为第 8，乾为第 1，坤为第 64。

### 三 · 卦变：群作用与一般映射

传统卦变里的四种变换，数学性质并不相同：

- **错卦**：按位取反 `x ↦ x ⊕ 111111`——可逆对合（involution）
- **综卦**：位序反转 `(b₀…b₅) ↦ (b₅…b₀)`——可逆对合
- **变卦**：按动爻异或单位向量 `x ↦ x ⊕ eᵢ`——可逆
- **互卦**：由中间四爻决定 `64 → 16` 的**非单射映射**（4 对 1）——不可逆，不属于任何群

错与综两个对合生成一个克莱因四元群（Z₂²），本卦在群作用下的轨道封闭；互卦则是一般映射。分得清「群作用」与「一般映射」，正是这个项目的态度。

### 四 · 蒙特卡洛：把占卜交给大数定律

一键模拟两种起卦法各 1–100,000 次，频率分布直方图与理论概率线对比。关键差异在「变」的对称性：铜钱法老阴、老阳均为 1/8，对称；大衍揲蓍法老阴仅 1/16、老阳 3/16，两种爻变的概率明显不对称——古法的「变」稀少且偏重阳变。样本量越大，频率越贴合理论线。

首页背景是 **Rule 90 元胞自动机**——阴阳二值按「左右邻居异或」迭代，生长出谢尔宾斯基三角形分形。
